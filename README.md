# Networkwalks Cybersecurity Internship – Week 3

## Password Cracking Projects

This repository contains my Week 3 practical work completed as part of the Networkwalks Cybersecurity Internship.

I practiced two password-cracking methods using authorized lab files.

## Project Module 1: John the Ripper (JTR)

- Extracted password hashes from protected PDF files.
- Used John the Ripper and Johnny to perform password-cracking tasks.
- Tested the recovered passwords by opening the protected files.

## Project Module 2: Networkwalks Tools

- Used the Networkwalks Hash Calculator to generate PDF hashes.
- Used the Networkwalks Password Cracker to attempt password recovery.
- Verified the recovered passwords with the lab files.
